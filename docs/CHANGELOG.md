# История изменений Menutor

## Текущая ветка

- API выдаёт разрешения CORS только для явно настроенных origins. Штатный веб-интерфейс продолжает обращаться к API через прокси на том же origin.
- Ошибки импорта CSV и JSON понятнее описывают проблемы с данными. При неизвестной единице измерения продукта сообщение указывает запись и поле. При техническом сбое показывается общее сообщение, а изменения из файла откатываются.
- При регистрации проверяется формат email. Если адрес введён неверно, форма предлагает исправить его.

- При выходе или завершении сессии очищаются открытые данные и несохранённые черновики аккаунта во всех вкладках того же профиля браузера. Запоздалые ответы завершённой сессии не восстанавливают вход и не меняют данные после повторного входа.

- Пароль аккаунта можно изменить только с проверкой текущего пароля. `PATCH /api/auth/me` принимает `nickname` и отклоняет запросы с полем `password` с кодом `422`.
- Категории продуктов и рецептов стали личными. Для новых аккаунтов создаются стартовые категории, а при обновлении существующей базы миграция переносит связи на личные справочники.
- Поиск продуктов и рецептов применяется ко всему каталогу до разбиения результатов на страницы.
- Backend применяет миграции Alembic при запуске.
- HTTP-запросы используют отдельные сессии БД. Незавершённые изменения откатываются при завершении запроса.
