# Планировщик меню

**Первый выпуск:** 0.1.0. Копирование и PDF появились в 0.7.1, мобильные режимы «Неделя», «День» и «Приём пищи» — в 0.10.0.

Недельная сетка распределяет рецепты и отдельные продукты по дням и приёмам пищи. Она служит исходными данными для сводки приготовления и покупок.

При добавлении блюда приложение предлагает количество по составу семьи. В ячейке можно изменить количество, порядок и размещение. План сохраняется по мере работы. На телефоне навигация позволяет перейти от всей недели к одному приёму пищи.

**Как пользоваться.** Создайте меню, добавьте блюда и проверьте порции. Для повторного использования скопируйте меню. Для печати выгрузите его в PDF. [Пошаговый сценарий](../user_guide.md#составить-меню-на-неделю).
