# Пищевые предпочтения

**Первый выпуск:** 0.13.0. Выбор категорий рецептов появился в 0.13.1.

Предпочтение помогает проверить, подходит ли блюдо выбранному члену семьи. Правила можно назначить нескольким людям. Планировщик использует их для подсказок о совместимости.

- **Блокировать** — совпадение с любой заданной категорией продуктов или рецептов делает блюдо несовместимым.
- **Аллергия** — совпадения по конкретному продукту, категории продукта или категории рецепта проверяются независимо. Достаточно одного совпадения.
- **Разрешать** — для каждого заданного списка категорий все проверяемые позиции должны входить в список. Позиция без категории не проходит соответствующую проверку.

Проверка учитывает продукты и категории вложенных рецептов. Например, блокировка категории «Молочные» затронет блюдо, в котором молочный ингредиент находится внутри соуса. Если дополнительно заблокировать категорию рецептов «Супы», будут отмечены и супы без молочных продуктов.

**Как пользоваться.** Создайте правило, назначьте его участнику и выберите этого участника в планировщике. [Сценарий настройки](../user_guide.md#настроить-предпочтения-семьи).
