# Штучные рецепты

**Первый выпуск:** 0.7.0.

Штучный режим удобен для блюд, которые раскладывают поштучно, например блинов, котлет или маффинов. Рецепт связывает порцию с числом штук.

Планировщик показывает порции и штуки. Если изменить число штук в ячейке, покупка ингредиентов рассчитывается для нового количества с учётом соотношения штук и порций.

**Как пользоваться.** Включите штучный режим в карточке рецепта, задайте число штук на порцию и добавьте блюдо в меню. При необходимости уточните количество в ячейке. [Руководство](../user_guide.md#добавить-подрецепт-или-блюдо-в-штуках).
