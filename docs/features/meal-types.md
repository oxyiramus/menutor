# Типы приёмов пищи

**Первый выпуск:** 0.14.0 для пользовательских типов.

Тип определяет строку или секцию в сетке меню и помогает расположить приёмы в порядке дня. При регистрации создаются завтрак, обед и ужин. Дополнительно можно создать до десяти пользовательских типов.

Типы упорядочиваются по времени. Базовые типы можно редактировать. Удаление доступно для пользовательских типов. Если такой тип уже используется, интерфейс предупреждает о затронутых меню перед подтверждением.

**Как пользоваться.** Откройте «Настройки → Типы приёмов пищи», добавьте тип, например «Полдник», и укажите время. Тип появится в планировщике.
