# Категории и цветовая маркировка

**Первый выпуск:** 0.1.0 для категорий, 0.11.0 для цветов. Версия перехода на личные каталоги в архиве релизов не указана.

Категории помогают искать и группировать продукты и рецепты. Это два отдельных справочника внутри аккаунта. При регистрации выдаётся стартовый набор, который можно редактировать. Название уникально в пределах соответствующего справочника пользователя.

Цвет категории используется в планировщике и PDF. При скрытии существующие записи сохраняют категорию, а список активных вариантов перестаёт её предлагать. Перенос и удаление позволяет выбрать замену для используемой категории.

**Как пользоваться.** Откройте нужный справочник в настройках. Чтобы снять используемую категорию с записей и сразу заменить её другой, выберите «Переместить и удалить» и подтвердите новую категорию. [Сценарий настройки](../user_guide.md#упорядочить-категории).
