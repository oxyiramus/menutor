# Импорт и экспорт

**Первый выпуск:** 0.4.0 для обмена каталогами и меню. TXT и CSV покупок доступны с 0.1.0, PDF меню, JSON и PDF покупок — с 0.7.1.

Файлы позволяют перенести справочные данные, поделиться планом и использовать покупки вне интерфейса.

| Данные | Форматы |
| --- | --- |
| Продукты | Импорт и экспорт CSV и JSON |
| Рецепты | Импорт и экспорт CSV и JSON, сокращённый JSON для упрощённого обмена |
| Меню | Импорт и экспорт JSON, выгрузка PDF |
| План приготовления | Копирование текста и скачивание TXT |
| Список покупок | Выгрузка TXT, CSV, JSON и PDF |

При импорте категории по имени сопоставляются с личным каталогом пользователя. Числовой идентификатор категории должен относиться к его каталогу. Пример файла можно скачать из диалога экспорта. Компактный JSON рецептов хранит сокращённый набор полей.

Если импорт прерывается, изменения из файла откатываются целиком. При ошибке данных API возвращает 422 с описанием проблемы. Для неизвестной единицы измерения продукта сообщение указывает запись и поле. При техническом сбое API возвращает 500 с сообщением «Не удалось выполнить импорт». Ответы об ошибках не раскрывают SQL, параметры базы данных или содержимое файла.

Запись данных при импорте выполняется в одной транзакции запроса. Если операция записи прерывается с исключением, изменения этой операции откатываются.

TXT и CSV покупок берут строки из открытого списка. JSON и PDF для списка с исходным меню рассчитываются по меню, поэтому итог может отличаться от отредактированного списка. Для списка без исходного меню JSON берёт текущие позиции, а PDF требует связь с меню.

**Как пользоваться.** Скачайте пример нужного формата, проверьте зависимости и импортируйте данные в порядке «продукты → рецепты → меню». Просмотрите отчёт о созданных, обновлённых и ошибочных записях. [Сценарий переноса](../user_guide.md#перенести-данные-с-помощью-файлов).
