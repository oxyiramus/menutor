# Каталог продуктов

**Первый выпуск:** 0.1.0.

Каталог связывает ингредиенты рецептов с тем, как продукты покупают. У продукта есть категория, рецептурная и закупочная единицы, коэффициент пересчёта и цена за закупочную единицу. Бренд и поставщик помогают различать товары и группировать покупки.

Единицы одной группы можно пересчитать автоматически. Если одна закупочная единица соответствует определённому количеству в рецепте, задайте коэффициент в карточке. Список покупок использует закупочное количество для расчёта стоимости и показывает рецептурное количество для сверки.

**Как пользоваться.** В разделе «Продукты» создайте карточку и заполните единицы и цену. Для поиска используйте строку поиска и фильтр по категории. Поиск применяется до пагинации. [Первоначальная настройка](../user_guide.md#подготовить-аккаунт-и-каталоги).
