# Сводка блюд и план приготовления

**Первый выпуск:** 0.9.0.

Сводка показывает, сколько готовить за выбранные приёмы пищи. Повторяющиеся блюда объединяются, вложенные заготовки и отдельные продукты показываются отдельно. При выборе части приёмов сводка пересчитывает количества.

Из выбранных позиций можно сформировать отдельный список покупок. Если заготовка уже есть, её можно исключить из выбора. Текстовая выгрузка содержит план с составом и количествами.

**Как пользоваться.** Откройте «Обзор блюд», отметьте нужные приёмы и заготовки, затем сформируйте список или скачайте план. [Сценарий подготовки](../user_guide.md#проверить-меню-и-подготовиться-к-готовке).
