# Семья и индивидуальное планирование

**Первый выпуск:** 0.1.0 для семейных коэффициентов, 0.12.0 для назначения блюд отдельным участникам.

Коэффициент показывает долю стандартной порции, которую нужно приготовить для человека. При планировании для группы коэффициенты выбранных участников складываются. Блюдо без явного назначения считается общим.

При выборе участников интерфейс показывает относящиеся к ним и общие позиции. Одинаковые блюда для разных участников в одной ячейке могут отображаться объединённо. Назначения относятся к рецептам, а отдельные продукты добавляются как общие позиции.

**Как пользоваться.** Заполните карточки семьи и выберите участников до добавления блюда. Для общего обзора переключитесь на «Все». [Сценарий планирования](../user_guide.md#составить-меню-на-неделю).
