# Списки покупок

**Первый выпуск:** 0.1.0 для расчёта, 0.8.0 для сохранённых списков, 0.15.1 для редактирования цены из списка.

Список покупок объединяет потребность из блюд и отдельные продукты меню. Количества пересчитываются в закупочные единицы, по ценам каталога рассчитывается стоимость. Список сохраняется как самостоятельный документ и запоминает исходное меню, если был создан из него.

Список можно создать пустым, сформировать из меню или сводки, скопировать и отредактировать. Отметка о покупке сохраняется отдельно. Редактирование цены за единицу пересчитывает позицию и отправляет новую цену в каталог.

**Как пользоваться.** Сформируйте список, проверьте количество, сохраните правки и отмечайте покупки. Для текущих строк используйте TXT или CSV. [Сценарий покупки](../user_guide.md#собрать-список-покупок) и [форматы выгрузки](data-exchange.md).
