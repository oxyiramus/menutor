# Каталог рецептов

**Первый выпуск:** 0.1.0. Ссылка и комментарий появились в 0.11.1.

Каталог хранит состав блюда, базовый выход и шаги приготовления. Одно блюдо можно планировать многократно с разным количеством порций, сохраняя исходную карточку.

В составе можно использовать продукты и [другие рецепты](nested-recipes.md). Вес нужен при масштабировании вложенного рецепта по граммам. Рецепты можно искать по всему каталогу, фильтровать по категории и выбирать для массового удаления. Перед удалением учитывайте связи с другими рецептами.

**Как пользоваться.** Создайте рецепт, добавьте ингредиенты и шаги, укажите порции и при необходимости вес, источник и комментарий. Для оценки бюджета включите [стоимость порции](recipe-cost.md).
