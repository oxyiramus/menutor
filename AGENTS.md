# Menutor для AI-агентов

Menutor — работающее приложение для семейного планирования меню. Пользователь ведёт каталоги продуктов и рецептов, планирует блюда на неделю с учётом состава семьи, формирует список покупок и оценивает стоимость блюд. Документация и пользовательский текст ведутся на русском языке.

## Где искать контекст

- [README](README.md) — назначение проекта и указатель документации.
- [Архитектура](architecture.md) — границы слоёв и потоки данных.
- [Руководство разработчика](CONTRIBUTIND.md) — Compose, локальный запуск, миграции и проверки.
- [Руководство пользователя](user_guide.md) — сценарии в интерфейсе.
- [История изменений](CHANGELOG.md) и [дорожная карта](roadmap.md) — выпущенные изменения и идеи соответственно.

## Как ориентироваться в коде

- Начинайте проверку контракта с маршрута в `backend/api` или экрана в `frontend/src`. Проследите запрос через прикладной сценарий и репозиторий, если задача касается данных.
- Храните бизнес-правила в домене и прикладных сценариях. Подключайте инфраструктурные реализации через точку сборки в `backend/composition`.
- При работе с пользовательскими данными проверяйте принадлежность записей и связанных объектов по действующим правилам. Для операций со справочниками проверяйте их область действия отдельно.
- Для проверки API используйте схемы маршрутов, OpenAPI и интеграционные тесты. UI-поведение сверяйте с экранами, хранилищами и тестами Vue.
- При документировании фичи обновляйте её страницу для долговременных правил, руководство пользователя для нового сценария, changelog для изменения релиза. При добавлении отдельной страницы включите её в список фич README.
- В `docs_archive` и `.agent_docs` лежат исторические материалы и планы. Сверяйте их утверждения с текущей реализацией.
